# ミートジャーキー (Meet Jerky)

Google Meetの字幕を自動的に記録・保存するChrome拡張機能です。

## 機能

- Google Meetの字幕テキストと発言者名を自動で記録
- セッション（会議）ごとに字幕履歴を管理
- 字幕ログのクリップボードコピー
- サイドパネルでのAI要約・チャット（OpenAI APIキーを設定した場合のみ）
- 記録データはブラウザ内にのみ保存（AI機能の使用時を除き外部送信なし）

## 利用ガイドライン

この拡張機能は、会議の字幕テキストを記録します。ご利用にあたっては、以下のガイドラインを守ってください。

### 参加者への事前告知

**会議の参加者に、字幕を記録していることを事前にお伝えください。**

字幕の記録は参加者の発言内容と氏名を含むため、他の参加者が記録されていることを認識していない状態での利用は、信頼関係やプライバシーの観点から問題となる可能性があります。

会議の冒頭で「議事録作成のために字幕を記録しています」と一言伝えることを推奨します。

### データの取り扱い

- 記録されたデータはお使いのブラウザのローカルストレージにのみ保存されます
- 通常の記録・閲覧では外部サーバーへのデータ送信は一切行いません
- AI要約・チャット機能を使用した場合のみ、対象セッションの文字起こしがOpenAIのAPIに送信されます（APIキー未設定の場合は送信されません）
- コピーしたテキストの管理・共有は利用者の責任で行ってください
- 不要になったセッションデータはポップアップ画面から削除できます
- セッションはデフォルトで10日間保持され、期限を過ぎると自動削除されます（設定画面で変更可能）
- 会議が終了して文字起こしが1件もないセッションは自動的に削除されます

### 適切な利用例

- 自分の振り返りのための議事録作成
- チームで合意の上での会議記録
- アクセシビリティ支援（聴覚に不安のある方の会議内容の確認）

### 不適切な利用例

- 参加者に無断での発言記録
- 記録データの無断共有・公開
- 個人の発言を監視目的で使用すること

## セットアップ

```bash
bun install
bun run dev
```

## ビルド

```bash
bun run build
```

### OpenAI APIキーのビルド時埋め込み（任意）

`.env` に `WXT_OPENAI_API_KEY` を設定してビルドすると、キーがバンドルに埋め込まれ、
設定画面でキーが未入力のときのフォールバックとして使われる（設定画面で入力したキーが常に優先）。

```bash
cp .env.example .env
# .env に WXT_OPENAI_API_KEY=sk-... を記入
bun run build
```

> ⚠️ 埋め込んだキーはビルド成果物から取り出せるため、このビルドを第三者に配布しないこと。
