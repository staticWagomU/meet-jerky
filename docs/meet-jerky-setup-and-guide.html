ミートジャーキー 導入と使い方

Google Drive で共有された zip ファイルを Google Chrome に入れて、Google Meet の字幕を自動で記録するための手順です。パソコンにくわしくない方でも、上から順に進めれば設定できます。

最初にここだけ確認してください

必要なもの Google Chrome（Windows / Mac のどちらでも可）
所要時間 初回の設定は10分ほどです
読む範囲 初回は「1」から「4」まで、普段は「5」以降を見ます

いちばん大事なお願い：フォルダを消さない・動かさない

この拡張機能は、アプリのようにパソコンへインストールされるものではありません。解凍してできたフォルダそのものを、Chrome が毎回読みに行きます。

そのため、次のことをすると拡張機能が動かなくなり、それまでに記録した文字起こしも見られなくなります。

  • フォルダを削除する（「ダウンロード」フォルダの整理で消してしまう事故がいちばん多いです）
  • フォルダを別の場所に移動する
  • フォルダの名前を変える

だから、Chrome に読み込ませる前に、フォルダを「ずっと置いておける場所」へ移してください。手順は「2. 解凍して、安全な場所に移す」で説明します。

この拡張機能は、会議の発言内容と参加者名を記録します。

会議の参加者に、記録していることを必ず事前にお伝えください。詳しくは「7. 会議参加者へのお願い」を読んでください。

1. Google Drive からダウンロードする

配布担当者から共有された Google Drive のフォルダ、または共有リンクを開きます。

zip ファイルを探します

meet-jerky-0.0.0-chrome.zip のような名前のファイルです。真ん中の数字は版によって変わります。

ダウンロードします

ファイルを右クリックして「ダウンロード」を選びます。画面右上のダウンロードボタンからでも構いません。

ダウンロードが終わるまで待ちます

通常は「ダウンロード」フォルダに保存されます。

Google Drive で「プレビューできません」と表示されても問題ありません。中身を見るのではなく、パソコンにダウンロードして使います。

2. 解凍して、安全な場所に移す

ここがこのガイドでいちばん大事な章です。「ダウンロード」フォルダに置いたまま使わないでください。

なぜ移すのか

Chrome は、読み込んだフォルダの場所を覚えていて、起動のたびにそこを見に行きます。フォルダが消えていたり、場所が変わっていたりすると、Chrome は「別のもの」または「無くなったもの」と判断します。「ダウンロード」フォルダは、パソコンの整理やブラウザの掃除で中身が消えやすい場所なので、置き場所として向きません。

Windows

解凍する

エクスプローラーで「ダウンロード」を開き、zip ファイルを右クリックして「すべて展開」を選び、「展開」を押します。

置き場所を作って移す

「ドキュメント」の中に chrome-extensions という名前のフォルダを新しく作り、解凍でできたフォルダをその中へドラッグして移動します。

ドキュメント\chrome-extensions\meet-jerky-0.0.0-chrome
Mac

解凍する

Finder で「ダウンロード」を開き、zip ファイルをダブルクリックします。同じ場所にフォルダができます。

置き場所を作って移す

「書類」の中に chrome-extensions という名前のフォルダを新しく作り、解凍でできたフォルダをその中へドラッグして移動します。

書類/chrome-extensions/meet-jerky-0.0.0-chrome

フォルダの中身を確認してください。移したフォルダを開くと、manifest.json というファイルと、icon などのフォルダが入っています。この manifest.json が直接見えている階層が、次の手順で選ぶフォルダです。

もしフォルダを開いたときに、中にもう1つ同じ名前のフォルダしか入っていない場合は、その内側のフォルダが正解です。

移し終わったら、「ダウンロード」フォルダに残っている zip ファイルは削除して構いません。使うのは、移動させたあとのフォルダだけです。

3. Chrome に読み込む

Google Chrome を開いて操作します。Edge や Safari ではなく、必ず Chrome を使ってください。

拡張機能の管理画面を開きます

Chrome のアドレスバー（URL を入力する欄）に chrome://extensions と入力して Enter キーを押します。

画面右上の「⋮」（点が縦に3つ）から「拡張機能」→「拡張機能を管理」でも開けます。

「デベロッパー モード」をオンにします

画面の右上にあるスイッチです。オンにすると、画面の左上にボタンが3つ増えます。

「パッケージ化されていない拡張機能を読み込む」を押します

増えたボタンのうち、いちばん左のものです。フォルダを選ぶ画面が開きます。

手順2で移動させたフォルダを選びます

manifest.json が入っているフォルダを選んで、「フォルダーの選択」（Mac では「選択」）を押します。

zip ファイルそのものではなく、解凍してできたフォルダを選ぶ点に注意してください。

「ミートジャーキー」が一覧に出れば成功です

カードが表示され、スイッチがオン（青色）になっていれば読み込み完了です。

Chrome を起動するたびに「デベロッパー モードの拡張機能を無効にする」という確認が出ることがあります。

これは故障ではありません。この画面が出たら「キャンセル」を押すか、×で閉じてください。「無効にする」を押すと、記録が行われなくなります。

4. ツールバーに表示させる

毎回使いやすいように、Chrome の右上に固定します。

パズルのピースのアイコンを押します

Chrome 右上、アドレスバーの右隣にあります。入っている拡張機能の一覧が出ます。

「ミートジャーキー」の横のピンを押します

ピンの絵が青くなれば固定完了です。ツールバーにアイコンが並びます。

最初の1回だけ、説明画面が出ます

アイコンを押すと、何を記録するかの説明が表示されます。内容を読んで「理解しました」を押してください。

5. 会議を記録する

特別な操作は要りません。Google Meet の会議に入れば、自動で記録が始まります。

いつもどおり Google Meet の会議に参加します

参加すると、字幕が自動的にオンになります。字幕が画面下に出はじめれば準備完了です。

画面の右下にある小さな表示を確認します

「RAW: 0」のような黒い帯が出ます。左の丸が緑なら記録中、赤なら記録できていない状態です。数字は取り込んだ字幕の件数で、話が進むと増えていきます。

字幕はオンのままにします

字幕をオフにすると記録が止まります。オフにしようとすると確認のメッセージが出るので、記録を続けたいときは「キャンセル」を押してください。

会議を退出します

退出ボタンを押す、タブを閉じる、どちらでも記録は自動で保存されます。

会議中に一度退出してしまっても大丈夫です。2分以内に同じ会議へ戻れば、同じ記録の続きとして扱われます。

字幕が出ない・赤いままのとき

会議の主催者が字幕を使えない設定にしている可能性があります。その場合は記録できません。また、字幕の言語設定が会議の言語と合っていないと、うまく文字にならないことがあります。

6. 記録を見る・コピーする

ツールバーのミートジャーキーのアイコンを押すと、これまでの会議の一覧が出ます。

見たい会議を選びます

会議名と日時が並んでいます。押すと、その会議の文字起こしが開きます。

「全文コピー」を押します

文字起こし全体がコピーされます。あとはメールや議事録のファイルに貼り付けてください。

必要に応じて名前を変えたり、削除したりします

鉛筆のボタンで会議名を変更、ゴミ箱の代わりの「削除」ボタンで記録を削除できます。

記録は自動で消えます

保存された会議は、10日を過ぎると自動的に削除されます（初期設定の場合）。ずっと残しておきたい会議は、ピン留め（画鋲のボタン）を押してください。ピン留めした会議は自動削除の対象外になります。

日数を変えたい場合は、次章と同じ設定画面で「セッション管理」から変更できます。

AI要約について

画面に「AI要約」のボタンがありますが、これは配布担当者が AI の利用設定を行っている場合のみ使えます。押すと、その会議の文字起こしが OpenAI（社外のサービス）に送信されます。案内がない場合は使わないでください。

7. 退出したら自動でファイルに保存する

毎回コピーして貼り付けるのが手間なときは、会議から退出した時点で自動的にファイルとして保存できます。初期設定ではオフなので、使いたい方だけ設定してください。

設定画面を開きます

ツールバーのミートジャーキーのアイコンを押し、右上の歯車のボタンを押します。

「自動ダウンロード」の欄を探します

「会議退出時に自動ダウンロードする」にチェックを入れます。

保存形式を選びます

迷ったら「テキスト (.txt)」で構いません。用途に応じて Markdown や JSON も選べます。

保存先フォルダを決めます

初期値は meet-jerky です。この名前のフォルダが、ブラウザのダウンロードフォルダの中に作られ、そこに保存されます。

「設定を保存」を押します

次の会議から、退出したときに自動でファイルが作られます。

項目 使う場面 注意点
保存形式 テキストは貼り付け用、Markdown は見出し付きの議事録用、JSON は他のシステムに取り込む用 迷ったらテキストで問題ありません。
保存先フォルダ 会議の記録を1か所にまとめたいとき ブラウザのダウンロードフォルダの中だけを指定できます。それ以外の場所には保存できません。
保存のたびに保存先を選ぶ 会議ごとに置き場所を変えたいとき オンにすると、退出のたびに保存先を尋ねる画面が出ます。自動ではなくなります。

ダウンロードフォルダ以外の場所に保存したい場合は、Chrome 側の設定でダウンロード先そのものを変更してください。拡張機能から指定できるのは、そのフォルダの中までです。

字幕が1件も記録できなかった会議は、ファイルは作られません。

8. 会議参加者へのお願い

この拡張機能は、参加者の発言内容と氏名を記録します。使い方を誤ると、信頼関係の問題になります。

会議の冒頭で、記録していることを必ず伝えてください。

「議事録作成のために字幕を記録しています」と一言添えるだけで構いません。参加者が知らないまま記録することは避けてください。

適切な使い方

  • 自分の振り返りのための議事録作成
  • チームで合意のうえでの会議記録
  • 聞き取りに不安のある方が、会議の内容をあとから確認する

してはいけない使い方

  • 参加者に無断で発言を記録する
  • 記録したデータを無断で共有・公開する
  • 特定の人の発言を監視する目的で使う

データの取り扱い

  • 記録したデータは、お使いのパソコンの Chrome の中だけに保存されます
  • 通常の記録・閲覧では、社外にデータが送られることはありません
  • AI要約の機能を使ったときだけ、その会議の文字起こしが OpenAI に送信されます
  • コピーしたテキストや保存したファイルの管理・共有は、使う人の責任で行ってください

9. 新しい版が配られたとき

改善版の zip が配布されたら、次の手順で入れ替えます。フォルダの場所は変えないでください。

新しい zip をダウンロードして解凍します

手順1・2と同じです。

今使っているフォルダの中身を、新しい中身に入れ替えます

手順2で作った chrome-extensions の中の、同じ場所・同じフォルダ名のまま中身だけを差し替えます。フォルダごと別の場所に置くと、Chrome は別の拡張機能として扱い、それまでの記録が見られなくなります。

Chrome で再読み込みします

chrome://extensions を開き、ミートジャーキーのカードにある更新（回転する矢印）のボタンを押します。

フォルダ名が版によって変わる場合（meet-jerky-0.0.1-chrome など）は、名前を今までと同じものに変えてから差し替えるか、判断に迷ったら配布担当者に確認してください。

10. 困ったとき

拡張機能が一覧から消えた／エラーと表示される

読み込んだフォルダを移動・削除・名前変更していないか確認してください。いちばん多い原因です。フォルダを元の場所に戻せば直ります。フォルダごと消してしまった場合は、手順1からやり直してください（過去の記録は戻りません）。

過去に記録した会議が全部消えている

フォルダを別の場所に移してから読み込み直すと、Chrome は「別の拡張機能」として扱うため、以前の記録が見えなくなります。元のフォルダがまだ残っていれば、元の場所に戻して読み込み直すと復帰します。

会議中に右下の丸が赤いまま／数字が増えない

字幕がオフになっていないか確認してください。字幕ボタン（吹き出しに CC のマーク）を押してオンにします。主催者が字幕を禁止している会議では記録できません。

Chrome を起動するたびに警告が出る

「デベロッパー モードの拡張機能を無効にする」という確認です。「キャンセル」または×で閉じてください。この方法で配っている拡張機能では通常の動作です。

自動ダウンロードでファイルが作られない

設定画面で「会議退出時に自動ダウンロードする」がオンになっているか確認してください。字幕が1件も記録できなかった会議では、ファイルは作られません。

会議名が「abc-defg-hij」のような文字になっている

会議に名前が付いていない場合、会議コードがそのまま表示されます。記録画面の鉛筆ボタンから、分かりやすい名前に変更できます。

このガイドに載っていない画面が出た場合は、操作せずに配布担当者または情報システム担当に相談してください。

11. 用語

拡張機能 Chrome に機能を追加する小さなプログラムです。ミートジャーキーもその1つです。
zip 複数のファイルを1つにまとめた形式です。使う前に「解凍」して、元のフォルダに戻す必要があります。
解凍（展開） zip ファイルから中身のフォルダを取り出すことです。Windows は右クリックから「すべて展開」、Mac はダブルクリックで行えます。
デベロッパー モード Chrome の拡張機能画面にあるスイッチです。社内で作った拡張機能を読み込むために必要です。
manifest.json 拡張機能の中身を Chrome に伝えるファイルです。このファイルが直接入っているフォルダを、Chrome に読み込ませます。
字幕（キャプション） Google Meet が発言を文字にして画面に出す機能です。ミートジャーキーは、この文字を読み取って記録します。
セッション この拡張機能では、1回の会議の記録のことを指します。

この資料は、配布する zip ファイルと一緒に Google Drive へ置いて使う想定です。手順どおりに進めても解決しない場合は、配布担当者または情報システム担当に相談してください。
